# Production Roadmap

## Track A
Run Sanket, reproduce preprocessing, benchmark.

## Track B
Integrate ISLTranslate and build signer-disjoint continuous translation benchmark.

## Track C
Benchmark ST-GCN + Transformer + CTC.

## Track D
Build streaming runtime, confidence policy, API, UI and TTS.

## Track E
Security, privacy, load tests, model registry, rollout and rollback.

## Track F
Larger vocabulary, signer diversity, mobile/on-device runtime, multilingual output and optional reverse translation.
