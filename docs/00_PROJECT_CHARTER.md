# Project Charter

## Product
ISL Translator

## Problem
Translate Indian Sign Language captured through a camera into English text and optional speech for communication with non-signers.

## Product boundary
The system is a translation aid. It must communicate uncertainty and must not imply perfect interpretation.

## Primary users
- ISL signers
- families/caregivers
- education/accessibility environments
- public-service communication contexts

## Success
Success requires measurable translation quality, unseen-signer generalization, real-time performance, privacy, security, reproducibility, and operational reliability.

## Initial objective
Run and benchmark the pretrained Sanket model using its exact documented model/preprocessing contract, then compare it with continuous ISL alternatives.

## Non-goals
Do not reduce ISL to alphabet recognition or a fixed gesture demo.
